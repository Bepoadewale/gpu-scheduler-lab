# Daily Engineering Task

Read control files, fetch/inspect branch/PR, run `make verify`, then ask: “What is the highest-value remaining blocker preventing PORTFOLIO COMPLETE — LOCAL-FIRST SCOPE?” Advance that P0 scheduler experiment. Do not select polish/P2 work while blockers remain. Verify current upstream version before applying manifests. Record actual cluster observations; never infer GPU behavior. Update status/backlog, commit/push branch only and report results.

As the project approaches completion, clean-room reproducibility becomes P0. Before declaring completion: tear down Project-owned infrastructure; verify teardown; bootstrap clean; smoke; run primary and failure/security demos; validate; clean again; bootstrap a second time; and record evidence. If either rebuild fails, fix it before cosmetic work.
